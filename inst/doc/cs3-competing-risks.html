About this computer exercise.

This exercise covers Chapter 12 of Collett, Modelling Survival Data in Medical Research (4th ed.), and the R code in Section 17.12 of the same book. The subject is competing risks: what happens to a survival analysis when an individual can die from one of several causes, and one event rules out the others.

The exercise follows the logic of the chapter. It starts with the Kaplan–Meier estimate of the survivor function for each cause, then introduces the cause-specific hazard and the cause-specific cumulative incidence function. It uses Cox regression to model cause-specific hazards and the Fine and Gray model to model cumulative incidence. The two data sets are liver (graft failure after a liver transplant, Examples 12.1–12.6) and mice (irradiated mice, Example 12.7).

Competing risks

With competing risks, the event indicator \(C\) records which of the \(m\) possible end points occurred. The observed data are pairs \((t_i, c_i)\), where \(t_i\) is the observed time and \(c_i = 0\) denotes a censored observation. An event from one cause precludes events from the other causes for the end point being studied.

Cause-specific cumulative incidence functions

The cause-specific cumulative incidence function \[F_j(t) = P(T \le t, C = j) = \int_0^t h_j(u)\,S(u)\,du\] is the probability of having failed from cause \(j\) by time \(t\), with all causes present. It increases to \(\pi_j = P(C = j)\), the ultimate probability of failure from cause \(j\), which is less than 1 when another cause has positive probability. Because \(F_j(\infty) \ne 1\), \(F_j\) is called a subdistribution function.

Modelling cause-specific hazards

The cause-specific hazard for cause \(j\) is \[h_j(t) = \lim_{\delta t \to 0} \frac{P(t \le T \le t + \delta t,\ C = j \mid T \ge t)}{\delta t},\] the instantaneous failure rate from cause \(j\) among those who are still alive and event-free. It is modelled with a Cox regression model, \(h_{ij}(t) = \exp(\beta_j^\top x_i)\, h_{0j}(t)\), and, as Collett shows in Section 12.4.1, the partial likelihood factorises into one contribution per cause. We can therefore fit one Cox model per cause to the cause-specific survival data, with failure times from other causes treated as censored.

The Fine and Gray competing risks model

Fine and Gray (1999) model the cumulative incidence function using the subdistribution hazard function, or subhazard, \[\lambda_j(t) = -\frac{d}{dt}\log\{1 - F_j(t)\} = \frac{f_j(t)}{1 - F_j(t)}.\] Their proportional subhazards model is \(\lambda_{ij}(t) = \exp(\beta_j^\top x_i)\,\lambda_{0j}(t)\). An individual who has already experienced a competing event remains in the risk set, with weights that account for censoring. The model can be expressed in terms of the baseline cumulative incidence function: \(F_{ij}(t) = 1 - \{1 - F_{0j}(t)\}^{\exp(\beta_j^\top x_i)}\).
