1. From a clinical question to a time-to-event data set

A survival analysis starts with four decisions: the time origin, the time scale, the event and the censoring mechanism. These decisions are part of the estimand, not a technical detail, and are the same ingredients used throughout Lecture 1 (see the censoring and recruitment slides). The help pages (?iud, ?breast, ?prostate, ?melanoma, ?pulmonary, and ?sta310r::myeloma) give the background of each study.

3. True or false (no programmiong required)?

  1. A patient censored at 10 months is still in the risk set at 12 months.
  2. If censoring is informative, the Kaplan–Meier estimate is always biased upwards.
  3. The hazard \(h(t)\) is the probability of dying at time \(t\).
  4. Administrative censoring at the end of a study is usually independent censoring, provided the analysis time was specified before the data were examined.
  5. Left censoring means that the true event time is smaller than the observed time, and interval censoring means that the event time is known only to lie in an interval.
  6. Study time is calendar time in the study, while patient time is measured from each patient’s own time origin. Administrative censoring at a fixed calendar date therefore produces different patient-time censoring times for patients recruited at different dates.

2. The empirical survivor function when there is no censoring

The pulmonary data contain the survival times of 11 men with pulmonary metastasis from osteosarcoma, with no censoring. The empirical survivor function is simply the proportion of men whose survival time is at least \(t\): \[\hat S(t) = \frac{\text{number with survival time} \ge t}{n}.\] The estimated curve is a step function, constant between adjacent death times and decreasing at each death time. This is the “estimation of the survival function” idea from Lecture 1 (slides 15–18), where, with no censoring, \(\hat S(t)\) is simply the proportion still event-free at \(t\).

4. Explain why this code is useful (interpret what it does, include comments and possibly rewrite it in a more readable way). Then run it and look at the resulting table:

  mutate(
    n_at_least = map_int(time, \(t) sum(pulmonary$time >= t)),

3. Kaplan–Meier

The iud data contain the times, in weeks, to discontinuation of an intrauterine device because of menstrual bleeding problems, for 18 women. Nine times are events and nine are censored. This is the data set used in Collett’s Examples 2.3–2.10.

The Kaplan–Meier estimator multiplies the survival factors at each event time (Lecture 1, slides 19–22): \[\hat S(t)=\prod_{j:\,t_{(j)}\le t}\left(1-\frac{d_j}{n_j}\right),\] where \(d_j\) is the number of events at the event time \(t_{(j)}\) and \(n_j\) the number at risk just before it. Question 9 reproduces this product by hand.

10. The Kaplan–Meier-type hazard estimate in the interval from \(t_{(j)}\) to \(t_{(j+1)}\) is \[\hat h(t)=\frac{d_j}{n_j\tau_j},\qquad \tau_j=t_{(j+1)}-t_{(j)}.\] The estimate is not defined after the final death time, because the last interval is open-ended.

  1. Compute \(\hat h(t)\) for the event times in the iud data by:
event_times <- sort(unique(iud$time[iud$status == 1]))
(haz <- tibble::tibble(
  t = event_times,
  tau = c(diff(event_times), NA_real_),
  n = map_int(event_times, \(t) sum(iud$time >= t)),
  d = map_int(event_times, \(t) sum(iud$time == t & iud$status == 1)),
  h = d / (n * tau)
))
