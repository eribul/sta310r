This vignette presents dataset_by_exercise, the index that links every data set in sta310r to the worked examples in Collett (2023) that use it. The same index is available as a data set, so you can filter and sort it in R rather than reading it here.

The dX.Y aliases

Each example that uses a data set gives that data set an alias dX.Y, where X.Y is the number of the example. For example, Example 3.7 uses the myeloma data, so d3.7 is an alias for myeloma:

identical(d3.7, myeloma)
#> [1] FALSE
dim(d3.7)
#> [1] 48 10

A data set that is used in more than one example has one alias per example. The aliases are ordinary data objects in the package, so d3.7 works after library(sta310r) just like myeloma does, and ?d3.7 opens the help page of the data set. The index below is the authoritative list of which alias belongs to which example.

The cirrhosis study is a special case. Example 8.4 uses three forms of the same data: cirrhosis (the baseline values, alias d8.4), cirrhosis_lbr (the log-bilirubin measurements in long format) and cirrhosis_cp (the counting process format). Only the baseline object has the alias; the other two are listed with the same example but without an alias.

Using the index in R

Because the index is a data frame, you can query it directly:

# Which data set does Example 8.3 use?
dataset_by_exercise$dataset[dataset_by_exercise$example == "8.3"]
#> [1] "ovarian" NA        NA        NA        NA        NA

# Which examples use the myeloma data?
subset(dataset_by_exercise, dataset == "myeloma", c("alias", "example"))
#>    alias example
#> 3   d1.3     1.3
#> 6   d2.2     2.2
#> 10  d2.6     2.6
#> 22  d3.2     3.2
#> 25  d3.5     3.5
#> 27  d3.7     3.7
#> 28  d3.8     3.8
#> 29  d3.9     3.9
#> 35 d3.15    3.15
#> 37 d3.17    3.17
#> 38 d3.19    3.19
#> 39 d3.20    3.20
#> 44  d4.5     4.5
#> 47  d4.8     4.8
#> 48  d4.9     4.9

# All data sets used in Chapter 3
unique(dataset_by_exercise$dataset[dataset_by_exercise$chapter == 3])
#> [1] "breast"   "myeloma"  "hyper"    "prostate" NA

The index is generated by data-raw/dataset_by_exercise.R. If a new data set is added, or the example mapping changes, update that script and re-run it; it recreates both dataset_by_exercise and the dX.Y aliases.

Reproducing the book’s analyses

The help page of every data set shows how the analyses in Collett (2023) are carried out in R, with a comment for each example number. Each page has two parts:

  • Collett (2023), Chapter 17 style uses the functions and packages of the book’s own R chapter: survival::survfit(), survival::coxph(), survival::survdiff(), survival::survreg(), survival::cox.zph(), survival::tmerge(), survival::survSplit(), penalized::penalized(), eha::pchreg() and cmprsk::cuminc() / cmprsk::crr().
  • Modern tools repeats the same analysis with newer packages: ggsurvfit, flexsurv, coxme, icenReg, tidycmprsk, broom, rms and glmnet.

For example, ?gastric shows the piecewise treatment effect of Examples 11.2 and 11.3, and ?iud shows the conjugate Bayesian analysis of Examples 16.1 to 16.3 alongside the parametric models of Examples 5.1 to 5.4. Where the book uses a package that is not a dependency of this package, the help page says so in a comment and uses a runnable equivalent.
