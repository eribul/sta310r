Overview

sta310r contains the 33 data sets that accompany Collett (2023), Modelling Survival Data in Medical Research (4th edition), documented for the STA310 course at the University of Gothenburg. Each data set has a help page with the background of the study, the coded variables and references to the relevant chapter and examples in Collett (2023).

Data sets by example

Every data set that is used in a worked example of Collett (2023) has an alias dX.Y, where X.Y is the number of the example. See vignette("datasets-by-exercise") for the full index.

Computer exercises

The course exercises are vignettes in the package:

  • vignette("cs1-survival-data") — the questions for Computer exercise 1 (Chapters 1–2).
  • vignette("cs1-solutions") — the same document with the solutions included after each question.

The exercises use the data sets in this package together with the survival package. They do not rely on any estimator functions from sta310r; the analysis code is written with the standard survival workflow.
