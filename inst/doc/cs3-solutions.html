Solution 1

  1. Follow-up is time in days from transplantation, status is the death indicator, ptime is the day of platelet recovery and group is the leukaemia group.
with(bmt, table(status, precovery))
#>       precovery
#> status  0  1
#>      0  0 11
#>      1  2 10

There were 12 deaths, including 2 without prior recovery.

bmt |>
  filter(patient %in% c(7, 8)) |>
  select(patient, time, status, precovery, ptime)
#>   patient time status precovery ptime
#> 1       7   86      1         0    NA
#> 2       8  466      1         1   100

Patient 7 died without reaching the specified platelet level. The missing ptime reflects the absence of a recovery event. Patient 8 was alive at day 86, but recovered on day 100. Patient 8 was therefore still in the unrecovered group at the time of patient 7’s death.

Solution 2

cp <- tmerge(bmt, bmt, id = patient, death = event(time, status))
cp <- tmerge(
  cp,
  filter(bmt, precovery == 1),
  id = patient,
  recovered = tdc(ptime)
)

cp |>
  filter(patient %in% c(7, 8)) |>
  select(patient, tstart, tstop, death, recovered)
#>   patient tstart tstop death recovered
#> 1       7      0    86     1         0
#> 2       8      0   100     0         0
#> 3       8    100   466     1         1

Each row represents \((\mathrm{tstart},\mathrm{tstop}]\). Patient 7 contributes one interval ending in death. Patient 8 contributes one interval before recovery and another after recovery. Recovery changes the covariate for the next interval. Only the interval ending in death has death = 1.

c(
  patients = n_distinct(cp$patient) == nrow(bmt),
  deaths = sum(cp$death) == sum(bmt$status),
  positive_lengths = all(cp$tstart < cp$tstop)
)
#>         patients           deaths positive_lengths 
#>             TRUE             TRUE             TRUE
day <- bmt$time[bmt$patient == 7]

cp |>
  filter(tstart < day, day <= tstop) |>
  count(recovered)
#>   recovered  n
#> 1         0  3
#> 2         1 19

The interval ending at day contributes to its risk set, including the patient who dies then. A new interval starting exactly at day contributes only afterwards.

Solution 3

fixed <- coxph(Surv(time, status) ~ precovery + factor(group), data = bmt)
updated <- coxph(
  Surv(tstart, tstop, death) ~ recovered + factor(group),
  data = cp
)

tidy(fixed, exponentiate = TRUE, conf.int = TRUE) |>
  filter(term == "precovery")
#> # A tibble: 1 × 7
#>   term      estimate std.error statistic p.value conf.low conf.high
#>   <chr>        <dbl>     <dbl>     <dbl>   <dbl>    <dbl>     <dbl>
#> 1 precovery   0.0588      1.25     -2.27  0.0233  0.00509     0.680
tidy(updated, exponentiate = TRUE, conf.int = TRUE) |>
  filter(term == "recovered")
#> # A tibble: 1 × 7
#>   term      estimate std.error statistic p.value conf.low conf.high
#>   <chr>        <dbl>     <dbl>     <dbl>   <dbl>    <dbl>     <dbl>
#> 1 recovered   0.0983      1.23     -1.89  0.0592  0.00883      1.09
  1. The fixed analysis counts patient 8 as recovered even before the recovery day. Patients classified as ever recovered had to survive until recovery. Assigning that earlier time to the recovered group can create immortal time bias.

The time-dependent model compares the instantaneous death rates for patients who have recovered and those who have yet to recover, at the same time since transplantation and within the same disease group. Its estimated hazard ratio is closer to 1 than the fixed estimate, and its confidence interval includes 1. Platelet recovery is a prognostic marker that can reflect underlying health. The association alone gives no causal effect of inducing recovery.

Solution 4

ov <- ov |> mutate(age10 = (age - 60) / 10)

ph <- coxph(Surv(time, status) ~ age10 + factor(treat), data = ov)
tidy(ph, exponentiate = TRUE, conf.int = TRUE)
#> # A tibble: 2 × 7
#>   term           estimate std.error statistic p.value conf.low conf.high
#>   <chr>             <dbl>     <dbl>     <dbl>   <dbl>    <dbl>     <dbl>
#> 1 age10             4.33      0.459      3.20 0.00139    1.76      10.6 
#> 2 factor(treat)2    0.451     0.633     -1.26 0.209      0.130      1.56

The age hazard ratio compares women who differ by ten years of age at randomisation, within the same treatment group. The proportional hazards model uses the same ratio throughout follow-up.

varying <- coxph(
  Surv(time, status) ~ age10 + factor(treat) + tt(age10),
  data = ov,
  tt = \(x, t, ...) x * (t - 365) / 365
)
coef(varying)
#>          age10 factor(treat)2      tt(age10) 
#>          1.415         -0.664         -0.741

All women in a given risk set are compared at the same event time. Using each woman’s eventual observed follow-up time as \(t\) would use information from after that risk-set comparison. At day 365 the interaction is zero, so the main age coefficient gives the log hazard ratio per decade at that time.

days <- c(100, 400)
b <- coef(varying)
tibble(
  day = days,
  hr_per_decade = exp(
    b[["age10"]] +
      b[["tt(age10)"]] * (days - 365) / 365
  )
)
#> # A tibble: 2 × 2
#>     day hr_per_decade
#>   <dbl>         <dbl>
#> 1   100          7.05
#> 2   400          3.83

The fitted age hazard ratio becomes smaller later in follow-up.

lr <- 2 * as.numeric(logLik(varying) - logLik(ph))
pchisq(lr, df = 1, lower.tail = FALSE)
#> [1] 0.465

The likelihood ratio test gives little evidence for the added term, and there are only 12 deaths. The point estimates alone do not establish a change with time. The partial log likelihoods can be compared directly because both models use the same patients and events.

Solution 6

first <- coxph(Surv(time, status) ~ treatment, data = rat_first)
ag <- coxph(
  Surv(start, time, status) ~ treatment,
  data = rat_intervals,
  cluster = rat
)

tidy(first, exponentiate = TRUE, conf.int = TRUE)
#> # A tibble: 1 × 7
#>   term      estimate std.error statistic p.value conf.low conf.high
#>   <chr>        <dbl>     <dbl>     <dbl>   <dbl>    <dbl>     <dbl>
#> 1 treatment    0.476     0.314     -2.36  0.0182    0.257     0.881
tidy(ag, exponentiate = TRUE, conf.int = TRUE)
#> # A tibble: 1 × 8
#>   term      estimate std.error robust.se statistic   p.value conf.low conf.high
#>   <chr>        <dbl>     <dbl>     <dbl>     <dbl>     <dbl>    <dbl>     <dbl>
#> 1 treatment    0.428     0.152     0.211     -4.03 0.0000562    0.283     0.647

The first model compares the rates of first tumour in the two groups among rats still tumour-free and under follow-up. The AG model compares the intensities of tumour detection among rats currently at risk, regardless of their previous tumour count. It uses a common baseline intensity across event orders.

ag_model_based <- coxph(
  Surv(start, time, status) ~ treatment,
  data = rat_intervals,
  robust = FALSE
)
tibble(
  variance = c("Model-based", "Cluster-robust"),
  coefficient = c(coef(ag_model_based), coef(ag)),
  standard_error = c(sqrt(vcov(ag_model_based)[1, 1]), sqrt(vcov(ag)[1, 1]))
)
#> # A tibble: 2 × 3
#>   variance       coefficient standard_error
#>   <chr>                <dbl>          <dbl>
#> 1 Model-based         -0.849          0.152
#> 2 Cluster-robust      -0.849          0.211

The estimated coefficients agree. The cluster-robust standard error in these data is larger. The fit uses the same risk sets and partial likelihood. The variance calculation allows contributions from the same rat to be dependent, treating different rats as independent clusters.

risk80 <- rat_intervals |> filter(start < 80, 80 <= time)
nrow(risk80)

The AG risk set includes all rats under observation and at risk on day 80. For the PWP second-tumour comparison, a rat must already have had a first tumour and still be at risk of its second at that time.

rat_intervals <- rat_intervals |>
  mutate(event_stratum = pmin(event_number, 5))

pwp <- coxph(
  Surv(start, time, status) ~ treatment + strata(event_stratum),
  data = rat_intervals,
  cluster = rat
)
tidy(pwp, exponentiate = TRUE, conf.int = TRUE)
#> # A tibble: 1 × 8
#>   term      estimate std.error robust.se statistic    p.value conf.low conf.high
#>   <chr>        <dbl>     <dbl>     <dbl>     <dbl>      <dbl>    <dbl>     <dbl>
#> 1 treatment    0.527     0.165     0.130     -4.94    7.84e-7    0.409     0.679

Both fits estimate a lower tumour intensity for the retinoid group. The PWP estimate is closer to 1 and its confidence interval is narrower in these data. The PWP comparison is made within event-order strata. The first four orders each have their own baseline intensity, and the fifth and later orders share another baseline. The model fits one treatment hazard ratio across these strata. A model with separate treatment coefficients by event order would answer a different question.

Solution 8

An AG model can address the first question by including all eligible admissions. For the second question, fit a PWP total-time model restricted to the second-admission stratum, or fit event-order-specific treatment coefficients and report the one for the second admission. Both approaches condition that comparison on a first admission. The clock can measure time since trial entry for both analyses.

A patient who cannot be admitted again while already in hospital is out of the risk set from admission to discharge. Use intervals that end at admission and resume at discharge. A patient whose stay lasts until the end of follow-up contributes no further at-risk time. Cluster standard errors by patient to allow for dependence among records for the same person.

  filter(event_number <= 4) |>
  mutate(gap = time - start)
pwp_total <- coxph(
  Surv(start, time, status) ~ treatment + strata(event_number),

tidy(pwp_gap, exponentiate = TRUE, conf.int = TRUE)

#>   <chr>        <dbl>     <dbl>     <dbl>     <dbl>   <dbl>    <dbl>     <dbl>
#> 1 treatment    0.570     0.185     0.188     -2.99 0.00281    0.394     0.824

The gap clock starts at randomisation for the first tumour and restarts after each tumour. A final censored interval contributes the time since the last tumour until censoring if its event order is included. Both fits use the same event orders, and the gap-time estimate is somewhat further below 1 in these data. The gap-time fit compares rats at the same elapsed time since the start of the current interval, within the same stratum. The total-time fit compares rats at the same elapsed time since randomisation.
